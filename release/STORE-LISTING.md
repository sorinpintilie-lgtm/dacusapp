## Privacy answers

What the app and its backend actually handle (checked against the code, Oct 2026):

| Data | Collected | Purpose | Linked to the user |
| --- | --- | --- | --- |
| Name, email | Yes, when an account is created | Account | Yes |
| Shipping address, phone | Yes, when the user saves an address | Delivery | Yes |
| Purchase history | Yes (orders placed from the app) | Order history, loyalty points | Yes |
| Product interactions (views, searches) | Only with the "Statistici anonime" consent on | Analytics, recommendations | Yes, when logged in |
| Device ID / push token | Yes, if notifications are allowed | Push notifications, session list | Yes |
| Payment card data | **No** — entered on Shopify's checkout, never in the app | — | — |
| Location, photos, contacts, camera | **No** | — | — |

- **App Store "App Privacy":** declare Contact Info (name, email, address, phone), Purchases, Identifiers
  (user ID, device ID) and Usage Data (product interaction). None used for tracking → no App Tracking
  Transparency prompt needed.
- **Google Play "Data safety":** same categories; data encrypted in transit (HTTPS); users can delete their
  account in the app (Setări → Șterge contul) — give the policy URL above as the deletion info page.
- **Encryption:** `ITSAppUsesNonExemptEncryption` is already `false` (HTTPS only).
